### Взаимодействие сервисов

| Откуда | Куда | Назначение | Тип взаимодействия |
|-|-|-|-|
| API | Users | Авторизация и управление пользователями | Cинхронное |
| API | Catalog | Получение каталога и управление товарами | Cинхронное |
| API | Orders | Создание и просмотр заказов | Cинхронное |
| API | Recommendation | Получение персонализированной ленты | Cинхронное |
| Orders | Payments | Создание платежа и получение его статуса | Cинхронное |
| Orders | Notifications | Уведомление об изменении статуса заказа | Асинхронное |
| Recommendation | Catalog  | Получение данных товаров | Синхронное |
